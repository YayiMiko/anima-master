# 低 CFG 提示词约束留档

这里保存的是面向 Turbo、CFG 1 等弱指令遵循工作流的旧版提示词约束实现，留档日期为 2026-07-22。

该方案会在主提示词 LLM 之后再次调用 LLM，生成优先 Tag、冲突删除项、画风加权和动态 Tag 数量上限。它还会让进入约束模式的任务跳过短内容扩写。当前 CFG 5 工作流不再启用这套逻辑。

目录中的三个 Python 文件是拆除前的完整原件，仅用于对照和恢复，不会被插件导入：

- `prompt_constraints.py`：约束规划、解析与应用。
- `prompt_pipeline.py`：第二次 LLM 调用和约束流水线。
- `prompt_builder.py`：约束结果的最终拼接。

如需恢复，不应只复制单个文件，应同时核对这三个文件与当时版本的测试和配置结构。
