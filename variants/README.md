# 版本变体留档

插件默认使用内置 `anima_t2i` 工作流、30 步和 CFG 5。`variants/` 保存可选版本变体；只有选择对应预设时才会加载。

当前包含 Turbo 变体：

- `turbo/workflows/`：千代turbo 使用的 ComfyUI API 工作流。
- `turbo/low_cfg_harness/`：面向 CFG 1 的提示词约束留档原件。
- `turbo/config.example.jsonc`：手动切换到 Turbo 时需要调整的配置示例。

图生图、同机自启、部署诊断、引用图解析、法术提取和图片反推不是版本变体，继续保留在主线代码中。其中图生图默认关闭，但仍可通过现有配置启用。

留档原件用于维护和恢复，不应直接覆盖当前运行文件。调整变体时，应同时核对工作流、采样参数、提示词模板和对应测试。
