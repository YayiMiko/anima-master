# 版本变体留档

插件根目录是当前启用和发布的普通版，使用内置 `anima_t2i` 工作流、30 步和 CFG 5。`variants/` 只保存未启用的版本变体，不会被普通版自动导入或加载。

当前仅归档 Turbo 变体：

- `turbo/workflows/`：Turbo ComfyUI API 工作流。
- `turbo/low_cfg_harness/`：面向 CFG 1 的提示词约束旧实现。
- `turbo/config.example.jsonc`：切换到 Turbo 时需要调整的配置示例。

图生图、同机自启、部署诊断、引用图解析、法术提取和图片反推不是版本变体，继续保留在主线代码中。其中图生图默认关闭，但仍可通过现有配置启用。

归档内容用于未来分支或恢复，不应直接覆盖普通版文件。恢复某个变体前，应同时核对工作流、采样参数、提示词模板和对应测试。
