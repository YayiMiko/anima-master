# 指令速查

`/anm` 也可写成 `/anima` 或 `/comfyui`。发送 `/anm` 或 `/anm 帮助`可在聊天中查看常用指令。

| 指令 | 用途 |
| --- | --- |
| `/anm <描述>` 或 `/anm 生图 <描述>` | 自然语言生图 |
| `/anm 多人 <描述>` | 生成 2–4 人画面 |
| `/anm 无优化 <tags>` | 原样使用 tags，不经过 LLM 优化；别名 `/anm 原样` |
| `/anm 改图 <要求>` | 引用图片后改图；需要开启 `img2img_enabled` |
| `/anm 解析法术` | 读取图片内嵌的提示词和参数 |
| `/anm 反推` | 根据图片内容反推 tags |
| `/anm 状态` | 查看 ComfyUI 和模型是否就绪 |
| `/anm 添加角色 <名称>=<tags>` | 新增或覆盖固定角色 |
| `/anm 创建画师预设 <名称>=<tags>` | 保存并启用画师预设 |
| `/anm 追加画师预设 <名称>=<tags>` | 追加画师预设内容 |
| `/anm 切换画师预设 <名称>` | 切换画师预设 |
| `/anm 查看画师预设` | 列出画师预设 |
| `/anm 删除画师预设 <名称>` | 删除画师预设 |

画师预设命令的旧名“画师组”仍可使用。`放大`、`抠图`、`去背景`仍在开发中，默认不可用。

## 单次指定尺寸

在描述开头写`竖图`、`横图`、`方图`、`长竖图`或`宽屏`，插件会从配置的`allowed_sizes`里选比例最接近的一项。也可以明确写`1024x1536：描述`，或在末尾加`--尺寸 1216x832`。明确指定的尺寸不在可用列表中时，插件会列出可选尺寸，不会静默替换。

```text
/anm 生图 竖图：一个女孩站在梨花树下
/anm 生图 少女站在河岸 --尺寸 1216x832
```

需要排障时，优先阅读[故障排查](troubleshooting.md)。
